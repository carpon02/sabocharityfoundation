## 🚀 Featured Project

<div align="center">

### 🌟 Sabo Ibadan Youth Charity Foundation

</div>

> A production-ready full-stack platform built to power the Sabo Ibadan Youth Charity Foundation — enabling online donations, event management, volunteer onboarding, and admin analytics.

| Layer | Stack |
|-------|-------|
| **API** | Node.js + Express + MongoDB Atlas |
| **Customer App** | React 19 + Vite + TailwindCSS 4 + Redux Toolkit |
| **Admin Dashboard** | React 19 + Vite + TailwindCSS 4 |
| **Payments** | Paystack (test + live) |
| **Auth** | JWT + Google OAuth |
| **Media** | Cloudinary |
| **Monitoring** | Sentry |
| **CI/CD** | GitHub Actions |

[![Repo](https://img.shields.io/badge/View_Repo-sabocharityfoundation-6E57F7?style=for-the-badge&logo=github)](https://github.com/carpon02/sabocharityfoundation)
